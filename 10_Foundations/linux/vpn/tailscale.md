https://tailscale.com/

Linux:

1. Go to tailscale website dashbord
2. Click 'Add device' in 'Network -> Machines' section
3. Select 'Linux Server'
4. Click 'Generate Install Script'
5. Execute generated install script on linux server
6. After installation you can manage tailscape connection using:
   ```sh
   tailscale up
   tailscale status
   tailscale down
   ```

Android:

1. Download Tailscale android app
2. Sign in
3. Inside app, click toggle device connection for tailscale network
